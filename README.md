# Спектры квазаров — лаборатория

Интерактивная учебная лаборатория для проекта «Сириус.Лето» 2026/27: спектры квазаров и блазаров, поиск красного смещения по линиям, лес Лайман-альфа и космологический калькулятор. Статический сайт без сборки и внешних зависимостей — открывается по `index.html` из корня репозитория.

## Разделы

- **Карта неба** — снимок участка SDSS; квазары отмечены кружками, цвет и подпись — красное смещение.
- **Спектр и z** — спектр выбранного объекта, ручной и автоматический поиск z, тренажёр «незнакомый квазар». Работает поиск по имени, RA и z, сортировка каталога и постоянная ссылка на объект (`#tab=spec&q=<id>`).
- **Выборка** — таблица всех квазаров участка, гистограмма расстояний, «разрез» Вселенной и экспорт в CSV.
- **Эпохи и блазары** — композитные спектры разных эпох и сравнение блазаров со средним квазаром.
- **Лес Лайман-альфа** — доля поглощённого света D_A и число линий на 100 Å в зависимости от z.
- **Калькулятор** — расстояния и возраст Вселенной в плоской модели ΛCDM (Planck 2018).
- **Теория** — формулы, лабораторные длины волн линий, глоссарий и список источников.
- **Итоги** — критерии успеха, главные выводы и объекты, найденные контролем качества.

## Данные

- `data/quasars.js` — 42 квазара участка RA 180–181,5°, Dec 30–31,5° со спектрами;
- `data/forest.js` — 40 далёких квазаров для леса Лайман-альфа; подгружается по требованию (при выборе набора, в тренажёре или по ссылке на объект);
- `data/blazars.js` — 7 блазаров;
- `data/results.js` — результаты анализа: z, расстояния, метрики леса, композиты, критерии;
- `data/sky.jpg` — снимок участка неба; `data/thumbs/` — миниатюры объектов участка.

Источник данных — Sloan Digital Sky Survey DR17 (SkyServer, spec-lite). Условия, лицензии и политика конфиденциальности — `privacy.html`.

## Как открыть

Достаточно открыть `index.html` в браузере. Для проверки удобнее поднять локальный сервер из корня репозитория:

```powershell
python -m http.server
```

и откройте адрес, который напечатает сервер (по умолчанию <http://127.0.0.1:8000/>).

Сайт использует `localStorage` только для сохранения введённых вами значений z; данные никуда не отправляются. Внешние сервисы (SkyServer, Aladin Lite) открываются только по щелчку по ссылке.

## Технологии

HTML, CSS и JavaScript без сборщиков, npm и внешних CDN. Графики рисуются на `<canvas>`, карта неба — SVG поверх снимка. Сайт рассчитан на GitHub Pages, поэтому в корне лежит `.nojekyll`.
